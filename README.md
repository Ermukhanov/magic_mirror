# «Сиқырлы айна» / «Волшебное зеркало» v2

Интерактивная AR/CV-игра для детского сада (дети 4–6 лет). Ребёнок встаёт перед камерой, выбирает героя рукой и превращается в голограмму-героя в сказочном костюме. **Лицо ребёнка всегда остаётся настоящим**, а видео не сохраняется и никуда не отправляется (100% офлайн).

---

## 🇰🇿 Қазақша нұсқаулық (Нұсқаулық)

### 1. Жобаның ерекшеліктері
- **Толық қазақ тіліндегі интерфейс және дыбыстау:** Барлық жазулар, кейіпкерлердің аттары, тапсырмалар мен дауыстық нұсқаулар (`kk-KZ-AigulNeural` және `kk-KZ-DauletNeural`) қазақ тілінде. Мәтіндерді кодты өзгертпей `lang/kk.json` файлында түзетуге болады.
- **Оқуды білмейтін балаларға (4–6 жас) анимация арқылы үйрету:** Әр ойын алдында жартылай мөлдір «елес-силуэт» пен үлкен бағыттаушы жебелер қимылды көрсетеді. Дұрыс қайталағанда жиек жасыл түске боялып, салют атылады және *«Жарайсың!»* дауысы шығады.
- **8 бірегей кейіпкер (4×2 тор):**
  1. **Алпамыс** — орында жүгіру арқылы алтын **Тұлпарды** шақырады;
  2. **Томирис** — садақ тарту қимылымен алтын жебелер атады;
  3. **Өрмекші-адам** — қолын созып, тормен құбыжықты тартып алады;
  4. **Эльза** — екі қолын жанға созып, мұз толқынымен құбыжықтарды 3 секундқа қатырады;
  5. **Ледибаг** — алақан соғып, «Сәттілік шарасы» арқылы экранды тазартады;
  6. **Темір батыр** — екі алақанымен қуатты репульсор сәулесін жібереді;
  7. **Ғарышкер** — жоғары секіріп, салмақсыздықты қосады;
  8. **Пері** — төбесінде қолын бұлғап, құбыжықтарды көбелекке айналдырады.
- **Жоғары жылдамдық (30+ FPS @ 1280×720):** Камера ағыны (`Cam`), нейрожелі ағыны (`PoseWorker`), `OneEuro` сүзгісі және қозғалысты алдын ала болжау (`lead`) кідіріссіз жұмыс істейді.

### 2. Орнату және іске қосу
```bash
pip install -r requirements.txt
# Қажет болса, дауыстық файлдарды қайта генерациялау (файлдар sounds/voice/kk/ ішінде дайын тұр):
python tools/gen_voice.py
# Ойынды іске қосу:
python magic_mirror_v2.py
```

### 3. Тәрбиешіге және әзірлеушіге арналған пернелер
- `T` — **Тәрбиеші панелі** (қиындықты, уақытты, тілді, модуль жалаушаларын және жергілікті статистиканы басқару):
  - `A` — `ai_transform` (`AUTO` / `ON` / `OFF`) — нақты уақыттағы ЖИ-мен кейіпкерге айналу.
  - `W` — `video_worlds` (`ҚОСУЛЫ` / `ӨШІРУЛІ`) — тірі видео-әлемдер мен параллакс.
  - `X` — `fx_clips` (`ҚОСУЛЫ` / `ӨШІРУЛІ`) — видео-эффектілер мен салют.
  - `H` — `hero_art` (`ҚОСУЛЫ` / `ӨШІРУЛІ`) — кейіпкерлердің PNG-графикасы.
  - `Y` — `game_layer` (`ҚОСУЛЫ` / `ӨШІРУЛІ`) — ойын қабаты (жұлдыздар, құбыжықтар, мини-босс).
- `B` — **Әзірлеушінің отладка режимі (Debug Overlay)** | `C` — қаңқа координаттарын `debug_pose.json` файлына жазу (`python tools/replay.py`).
- `1..8` — Кейіпкерді пернетақтадан бірден таңдау | `S` — Калибровка/жаттығуды өткізіп жіберу.
- `P` — Пауза | `R` — Кейіпкер таңдау экранына оралу | `L` — Тілді ауыстыру (`ҚАЗАҚША` / `РУССКИЙ`).
- `D` — Қиындық деңгейі (АВТО / 1 / 2 / 3) | `G` — Ойын уақыты (45 / 60 / 90 сек).
- `+` / `-` / `M` — Дыбыс қаттылығын реттеу | `F` — FPS көрсету | `Q` — Шығу.

### 4. ЖИ модельдері, тексеру және SD-Turbo лицензиясы (Офлайн)
- Модельдер локалды түрде `models/sd-turbo` (`stabilityai/sd-turbo`, `fp16`) және `models/taesd` (`madebyollin/taesd`, `fp16`) бумаларында сақталады; ойын интернетсіз (100% офлайн) жұмыс істейді.
- **ЖИ жүйесін жылдам тексеру:**
  ```bash
  python tools/check_ai.py
  ```
  Бұл пәрмен CUDA қолжетімділігін, GPU атауын, локалды модельдердің бар-жоғын тексереді және сынақ кадрын жасап, генерация FPS мен VRAM шығынын көрсетеді.
- **Бұрыштағы ЖИ күйінің индикаторы:**
  - Қарапайым режим: «ЖИ: жүктелуде… / ЖИ: дайын / ЖИ: қате (себебі)» («ИИ: загрузка… / ИИ: готов / ИИ: ошибка»).
  - Баптау режимінде (`B`): ЖИ FPS, кадр кідірісі (мс) және VRAM көлемі көрсетіледі.
  - `ai_transform = "on"` кезінде модель жүктелгенше (60 сек дейін) процедуралық сауытты көрсетпей, баланың денесінде түрлену құйыны («ИИ готовится…») айналады.
- **Лицензия (SD-Turbo):** `stabilityai/sd-turbo` моделі **Stability AI Non-Commercial Research Community License** лицензиясымен таратылады (коммерциялық емес, білім беру, балабақша/мектеп көрмелері мен ғылыми-зерттеу мақсатында тегін қолдануға рұқсат етілген; коммерциялық мақсатта қолдану үшін Stability AI Enterprise/Creator лицензиясы қажет). `madebyollin/taesd` — **MIT License**.

## 🇷🇺 Инструкция на русском языке

### 1. Установка и запуск
```bash
pip install -r requirements.txt
# Проверка готовности ИИ (CUDA, локальные веса в models/, тестовый кадр и замер FPS):
python tools/check_ai.py
# Замер производительности ИИ и загрузка локальных моделей в models/ (Этап 1):
python tools/bench_ai.py
# Демо-стенд ИИ с камерой (слева живой кадр, справа ИИ-герой, клавиши 1-8, скрытая клавиша V для эскиза):
python tools/ai_demo.py
# Озвучка уже сгенерирована в sounds/voice/kk/*.mp3 и sounds/voice/ru/*.mp3.
# Запуск игры:
python magic_mirror_v2.py
```

### 2. Индикатор статуса ИИ и анимация превращения
- **Угловой индикатор статуса ИИ:**
  - Обычный режим: аккуратный индикатор в углу `«ИИ: загрузка… / ИИ: готов / ИИ: ошибка (причина)»`.
  - Режим разработчика (`B`): подробные метрики в реальном времени (`FPS ИИ`, `мс/кадр`, `VRAM`).
  - Прогрев модели происходит в фоновом GPU-потоке сразу при запуске игры (во время экрана приветствия и выбора героя).
  - При возникновении ошибок (нет папки `models/`, нет CUDA, исключение) причина сразу выводится через `print` в консоль и дублируется на экране.
- **Поведение при `ai_transform = "on"`:**
  - Если ИИ ещё загружается, игра не рисует процедурный костюм молча: выводится статус `«ИИ готовится…»` и вокруг ребёнка крутится анимация вихря превращения (до 60 секунд). Лицо и руки остаются живыми.
  - При `ai_transform = "auto"` сохраняется мягкий мгновенный откат на процедурный костюм.

### 2. Архитектура модулей и лицензия SD-Turbo
- `magic_mirror_v2.py` — точка входа и главный цикл игры (с защитой `try/except` и логированием в `magic_mirror.log`).
- `config.py` и `config.json` — параметры разрешения (`1280×720`), нейросети (`384×216`), промтов героев и флагов модулей (`ai_transform`, `video_worlds`, `fx_clips`, `hero_art`, `game_layer`).
- `tools/bench_ai.py` и `tools/ai_demo.py` — автоустановка зависимостей, скачивание `SD-Turbo (fp16)` и `TAESD` в `models/`, замер FPS/задержки/VRAM и интерактивное окно сравнения (живой кадр слева / ИИ-герой справа).
- **Лицензия SD-Turbo:** модель `stabilityai/sd-turbo` распространяется под лицензией **Stability AI Non-Commercial Research Community License** — бесплатна для некоммерческого, образовательного и исследовательского применения (включая демонстрации для комиссии в детском саду). Автоэнкодер `madebyollin/taesd` распространяется под лицензией **MIT**.
- `tracking.py` — потоки `Cam`, `PoseWorker`, фильтр `OneEuro`, предсказание позы костюма (`lead`), умный курсор руки (`CURSOR` без `lead`, с зоной досягаемости и магнитом `+25%`).
- `i18n.py` + `lang/kk.json`, `lang/ru.json` — словари локализации и кэшированная отрисовка шрифтов с поддержкой `Ә Ғ Қ Ң Ө Ұ Ү Һ І`.
- `heroes.py` + `ASSETS.md` — конфигурация 8 героев, загрузчик прозрачных PNG из `assets/<hero_id>/` с автоматическим фоллбэком на OpenCV.
- `render.py` — светлые сказочные пейзажи героев, параллакс облаков/звёзд, система частиц салюта и контрастная голограмма (с настоящим лицом ребёнка).
- `tutorial.py` — обучение через анимированный силуэт-призрак, живой неоновый скелет, шкалу точности позы `0%..100%` и жест-кнопки `3-2-1`.
- `game.py` — распознавание всех движений, монстры «Құбыжық», звёзды, тематические мини-боссы, комбо и автоподбор сложности.
- `audio.py` + `tools/gen_voice.py` — офлайн-озвучка и музыкальные темы героев через `pygame.mixer`.
- `ui.py` — сетка выбора `4×2`, 3-секундная калибровка в силуэте, игровой HUD, финальная медаль, панель воспитателя (`T`), отладка (`B`/`C`) и локальная статистика (`stats.json`).
